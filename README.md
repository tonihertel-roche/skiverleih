# ⛷️ Skiverleih – Ski- & Skizubehörverleih

Projekt im Kurs **Web-Programmierung** (DHBW Mannheim, 3. Semester).

Web-Anwendung zum Präsentieren und Ausleihen von Ski, Snowboards und Zubehör
(Stöcke, Schuhe, Helme, Protektoren) inkl. Warenkorb, Buchung für einen Zeitraum,
Familienregistrierung und Empfehlungen nach Gewicht, Können und Skityp.

## Arbeitsweise

1. Issue im Board von *To Do* nach *In Arbeit* ziehen und sich selbst zuweisen.
2. Eigenen Branch anlegen, z.B. `feature/warenkorb`.
3. Commit-Nachrichten mit Issue-Nummer, z.B. `Warenkorb-API ergänzt (#12)`.
4. Pull Request erstellen → Partner prüft (*Review / Test*) → mergen → Issue schließt sich mit `closes #12`.
5. Zeiten (inkl. Einarbeitung, Fehlersuche, Irrwege) laufend notieren – Pflicht für die Doku!
