🎯 Zielsetzung (Thema)

  • Ski (ggf. Snowboards) inkl. Bindungen & Zubehör (Stöcke, Schuhe, Helme, Protektoren …) ansprechend präsentieren.
  • Benutzergruppen: Anfänger / Fortgeschritten / Profi · Damen / Herren / Kinder · Carving / Touren / Telemark.
  • Ski-Merkmale: Länge, Kurvenradius, Gewichtsbereich. Stöcke: Länge, Tellergröße.
  • Ausleihzeiten anzeigen.
  • Pakete ggf. mit Rabatt (z.B. Ski & Stöcke).
  • Warenkorb + Ausleihe für bestimmten Zeitraum.

Bewertungskriterien laut Aufgabenstellung – zum Selbst-Check vor der Abgabe abhaken. (… und bitte KEINE Panik wegen der Bewertung! 🙂)

⚙️ Technische Randbedingungen

  • HTTP, HTML, JavaScript/TypeScript, CSS + Datenbank + serverseitige Programme.
  • Kein CMS (WordPress, Typo3, Joomla …)!
  • DB frei wählbar: MySQL/MariaDB, PostgreSQL oder MongoDB.
  • Frameworks/Sprachen/Bibliotheken weitgehend frei.
  • JS/TS im Client für eine angemessen umfangreiche Teilfunktion (z.B. AJAX) – Pflicht.
  • CSS direkt, SASS/SCSS oder Framework (Bootstrap, w3.css).
  • Responsiv: PC, Tablet, Smartphone (Test per DevTools reicht).

🖥️ Laufzeitumgebung

  • Rein lokal auf eigenem PC/Laptop (vermeidet Urheberrechtskonflikte) – oder eigener Server im LAN (z.B. Raspberry Pi).
  • Öffentlicher Server (z.B. AWS): rechtlich aufpassen, robots.txt mit User-agent: * / Disallow: /, nur per SSH-Tunnel zugreifen.
  • Server: Apache (XAMPP), Node.js + Express oder Spring Boot/Tomcat.

🧰 Software-Vorschläge

  • Node.js (nodejs.org) – Test: node --version
  • Express – npm install express
  • VS Code (code.visualstudio.com)
  • XAMPP (Apache, MariaDB, PHP, phpMyAdmin) – apachefriends.org; alternativ HeidiSQL
  • Postman zum Testen der API
  • Figma für UI-Entwurf
  • W3C-Validatoren für HTML/CSS
  • Browser-DevTools (Strg+Shift+I, „Toggle Device Toolbar“)

🧩 Frameworks (optional)

  • Bootstrap 5.3 – Doku
  • Vue.js · Angular (TypeScript) · React
  • Frontend ↔ Backend typischerweise über eine REST-API (HTTP-Anfrage an Endpunkt, Antwort als JSON).
